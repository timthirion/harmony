# plans/

Future directions for harmony. Each `.md` is a self-contained plan a future contributor (or claude) can pick up cold. No priority order — pick whichever sounds fun.

The unifying constraint across all plans is the current spirit of the project: **small, focused programs**. Each plan calls out its scope guard — where it would be tempting to grow beyond that constraint.

## Natural extensions (still one small program)

- [motif-per-tile.md](motif-per-tile.md) — Escher-style: warp a user-supplied vector motif into every tile.
- [mobius-animator.md](mobius-animator.md) — Emit frames of the tessellation transformed by a smooth hyperbolic isometry.
- [alternate-models.md](alternate-models.md) — Render the same tessellation in Klein disk, upper half-plane, and band models.

## Adjacent small programs (new binaries, same spirit)

- [euclidean-tiler.md](euclidean-tiler.md) — Companion program for regular Euclidean tilings and (later) wallpaper groups.
- [fundamental-domain-viewer.md](fundamental-domain-viewer.md) — Educational mode highlighting the fundamental polygon and its reflection tree.

## Bigger swings

- [interactive-viewer.md](interactive-viewer.md) — Real-time pan/zoom with adaptive tessellation depth.
- [print-poster-mode.md](print-poster-mode.md) — High-DPI, print-ready output.
